# 📁 Examples Directory

This directory contains example PlantUML diagrams, generation scripts, and use case demonstrations for the ArchiMate MCP Server.

## 📋 Directory Structure

```
examples/
├── README.md                    # This file
├── diagrams/                    # Generated diagram examples
│   ├── *.puml                  # PlantUML source files
│   ├── *.png                   # Rendered PNG images
│   └── *.svg                   # Rendered SVG images
├── rke2/                       # RKE2 Kubernetes examples
│   ├── CLUSTER_DOCUMENTATION.md
│   ├── USER_GUIDE.md
│   └── ...
└── generate_rke2_*.py          # Generation scripts

```

## 🎯 Usage

These examples demonstrate various ArchiMate modeling patterns and can be used as:

- **Reference implementations** for common architecture patterns
- **Starting points** for your own diagrams
- **Testing samples** for validating MCP server functionality
- **Educational materials** for learning ArchiMate methodology

## 🚀 Generated by ArchiMate MCP Server

All diagrams in this directory were generated using the ArchiMate MCP Server with enhanced validation and image generation capabilities.

For more information, see the main project documentation.
